## The project in one paragraph

ArtRock builds climbing walls. Today, showing climbers which holds belong to a route needs tape, expensive LED systems (around $13,750 for an LED board) or projectors that get blocked by the climber's shadow. Project Ascent uses the phone camera everyone already has: a wall is photographed and mapped once, and from then on, pointing a camera at it draws the chosen route onto the real holds, live. Routes can be picked from a shared database, generated by rules for the skill a climber wants to train, or built by hand. Because a camera is watching, the same system can later measure the climb itself — something LED walls can never do.
